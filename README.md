# QuickServe - Cafe Management System

## Chalate hobe
1. `index.html` browser-e open korun (double click) - eta ekai kaj korbe, data localStorage-e save hobe.
2. Optional (JSON Server diye): 
   ```
   npx json-server --watch db.json --port 3000
   ```
   Server chalu thakle orders `db.json`-e save hobe, na thakle automatic localStorage use hobe.

## Folder structure
- index.html
- css/style.css
- js/api.js, menu.js, cart.js, orders.js, kitchen.js, tables.js, app.js
- db.json (JSON Server-er demo data)
